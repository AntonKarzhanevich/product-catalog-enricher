# Product Catalog Enricher — Image Sourcing Automation (v0)

Автоматизация обогащения каталога, этап **v0**: унификация номенклатуры и автоматический поиск изображений для товаров из выгрузки 1С (по MPN/SKU). Обогащение описаний — следующая итерация (см. Roadmap).

## Проблема
У клиента (e-commerce) у значительной части товаров отсутствовали изображения. Ручное наполнение каталога занимало бы часы на партию позиций и фактически не выполнялось.

## Решение (v0 — изображения)
Python-пайплайн, который:
1. Загружает список товаров из выгрузки 1С (Excel/CSV)
2. Унифицирует наименования (нормализация номенклатуры)
3. Ищет изображения каскадом источников: API электронных каталогов (Mouser, Digi-Key) → веб-поиск
4. Формирует отчёт с оценкой уверенности (confidence) и файлы для загрузки в каталог

Проект разработан в AI-assisted режиме (Cursor / Claude): проектирование логики и структуры данных, обработка результатов, чтение, тестирование и доработка кода.

## Результат
- ~200 карточек обработано за 2 часа в автоматическом режиме (внедрение у клиента; работа ранее не выполнялась вообще)
- Каждый результат помечен источником и уверенностью: API каталогов (0.95) — доверенный, веб-поиск (0.5) — на ручную проверку

## Roadmap
- **v0 (текущий):** поиск изображений, отчёт с confidence
- **v1:** обогащение описаний через LLM (генерация карточек по характеристикам)
- **v2:** двусторонняя синхронизация с 1С (автозагрузка обогащённых карточек)

## Пример результата (синтетические данные)

| SKU | Было (выгрузка 1С) | Стало (после пайплайна) |
|-----|--------------------|--------------------------|
| A-1042 | STM32F103C8T6, без изображения | `images/web/STM32F103C8T6.jpg`, источник: веб-поиск, уверенность 0.5 (needs_review) |
| A-1045 | LM317T, без изображения | `images/mouser/LM317T.jpg`, источник: Mouser API, уверенность 0.95 |

Полный пример входа и выхода — в каталоге `demo/`.

## Стек
Python, API электронных каталогов (Mouser, Digi-Key), веб-парсинг, Excel/CSV

## Структура
- `src/napolnenie/` — пакет: парсинг выгрузок, источники изображений (Mouser, Digi-Key, веб-поиск), кэш, отчёты
- `tests/` — тесты
- `scripts/` — вспомогательные скрипты
- `config/` — правила нормализации и конфигурация источников
- `docs/`, `research/` — архитектура, этапы, исследование API

## Примечание
Коммерческие данные клиента не публикуются: в репозитории — обезличенная версия пайплайна.
