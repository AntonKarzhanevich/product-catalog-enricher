# Product Catalog Enricher

Автоматизация обогащения карточек товаров: унификация номенклатуры, автоматический поиск описаний и изображений через поисковые API.

## Проблема
У клиента (e-commerce) у значительной части товаров отсутствовали описания и изображения. Ручное наполнение каталога занимало бы часы на партию позиций и фактически не выполнялось.

## Решение
Python-скрипт, который:
1. Загружает список товаров из Excel/CSV
2. Унифицирует наименования (нормализация номенклатуры)
3. Автоматически ищет описания и изображения через поисковые API
4. Формирует заполненные карточки и сохраняет результат в структурированный файл

Проект разработан в AI-assisted режиме (Cursor / Claude): проектирование логики и структуры данных, обработка результатов, чтение, тестирование и доработка кода.

## Результат
- ~200 карточек (описание + изображения) за 2 часа в автоматическом режиме
- Работа, которую раньше в компании не делали вовсе, стала регулярным процессом

## Пример результата (синтетические данные)

| SKU | Было (выгрузка 1С) | Стало (после пайплайна) |
|-----|--------------------|--------------------------|
| A-1042 | STM32F103C8T6, без изображения | `images/web/STM32F103C8T6.jpg`, источник: веб-поиск, уверенность 0.5 (needs_review) |
| A-1045 | LM317T, без изображения | `images/mouser/LM317T.jpg`, источник: Mouser API, уверенность 0.95 |

Полный пример входа и выхода — в каталоге `demo/`.

## Стек
Python, API электронных каталогов (Mouser, Digi-Key), веб-парсинг, Excel/CSV

## Структура
- `src/napolnenie/` — пакет: парсинг выгрузок, источники изображений (Mouser, Digi-Key, веб-поиск), кэш, отчёты
- `tests/` — тесты
- `scripts/` — вспомогательные скрипты
- `config/` — правила нормализации и конфигурация источников
- `docs/`, `research/` — архитектура, этапы, исследование API
