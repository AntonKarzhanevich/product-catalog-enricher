# Поиск изображений для каталога запчастей ноутбуков — план

> Только бесплатные инструменты. Стратегия и принятие решений.  
> Актуально на: **26 мая 2026**

---

## Постановка задачи

Нужны качественные фотографии микрочипов и запчастей ноутбуков для товарного каталога. Требования: белый фон, достаточное разрешение, точное соответствие артикулу, возможность автоматизации на большом объёме позиций.

---

## Почему это нетривиальная задача

Обычный поиск в Google Images не подходит по трём причинам:

- По артикулу чипа возвращаются форумные посты, схемы, фото плат целиком — не изолированные фото компонента
- Нет гарантии белого фона и нужного ракурса
- Авторские права на найденные фото неизвестны

Специализированные источники решают все три проблемы сразу.

---

## Источники изображений: что и зачем

### Digi-Key API — основной источник ✅

Один из крупнейших дистрибьюторов электронных компонентов в мире. Хранит профессиональные фотографии на белом фоне для большинства позиций своего каталога.

**Условия доступа:** бесплатно, регистрация на developer.digikey.com.

**Лимиты на 26.05.2026:** подтверждено официальным FAQ Digi-Key — 1 000 запросов к Product Information API в день, 120 запросов в минуту. Превышение лимита возвращает ошибку 429.

**Покрытие:** сильное по контроллерам питания, чипам памяти, Wi-Fi модулям, EC-контроллерам. Слабее по специфическим BGA-видеочипам и снятым с производства позициям.

**Логика работы:** запрос по артикулу производителя → в ответе прямая ссылка на изображение товара.

---

### Mouser Search API — второй источник ✅

Аналогичный дистрибьютор, дополняет Digi-Key по позициям, которых там нет. Возвращает ссылки на фото в стандартном и высоком разрешении.

**Условия доступа:** бесплатно, регистрация на mouser.com/api-hub. Mouser одобряет заявки вручную — занимает 1–2 рабочих дня. Нужно зарегистрироваться заранее.

**Лимиты на 26.05.2026:** дневной лимит подтверждён сторонними клиентами и документацией — 1 000 запросов в день, аналогично Digi-Key. Mouser публично не афишировал этот лимит, но он существует.

**Важно:** официальный API — единственный рабочий способ. Прямой скрапинг сайта заблокирован на уровне Akamai Bot Manager.

---

### Google Custom Search JSON API — резервный источник ⚠️

**Статус на 26.05.2026:** API закрыт для новых пользователей. Существующие пользователи могут работать до 1 января 2027 года, после чего сервис будет отключён. Новые ключи не выдаются.

**Лимит:** 100 бесплатных запросов в день. Не более 10 результатов за запрос.

**Практический вывод:** если ключ уже есть — использовать как резерв до конца 2026 года. Если ключа нет — этот источник недоступен.

**Альтернатива от Google:** Vertex AI Search — официальная замена, но требует полноценной настройки Google Cloud и имеет корпоративное ценообразование. Не подходит как бесплатный резерв.

---

### Nexar / Octopart — для тестирования, не для production ⚠️

Агрегатор данных об электронных компонентах (принадлежит Altium). При регистрации выдаётся Evaluation app с пожизненным лимитом в 1 000 запросов — не ежемесячных, а суммарно за всё время. После исчерпания API не работает до оплаты. Имеет смысл только для разового тестирования перед выбором платного плана.

## Структура пайплайна

Два рабочих уровня + ручная очередь для незакрытых позиций:

```
Артикул + Название
      ↓
  Digi-Key API
  найдено? → Сохранить, пометить источник "digikey"
  нет ↓
  Mouser API
  найдено? → Сохранить, пометить источник "mouser"
  нет ↓
  Статус "не найдено" → очередь ручной обработки
```

Позиции со статусом «не найдено» выгружаются отдельным списком для ручного добора.

## Планирование по объёму каталога

### До 1 000 позиций

Наполнение за 1–2 дня. Дневные лимиты не являются ограничением. Запускается одним прогоном.

### 1 000 – 5 000 позиций

Лимит в 1 000 запросов/день на каждом API становится основным ограничением. При параллельном использовании обоих дистрибьюторов часть позиций распределяется между ними, и фактическая скорость выше. Реальное время наполнения: 3–7 дней.

### 5 000 – 10 000 позиций

Первичное наполнение займёт 1–2 недели при ежедневном запуске. Разумная стратегия: начать с позиций с наибольшим оборотом (ABC-анализ), остальные добирать постепенно.

### Свыше 10 000 позиций

Полностью бесплатный вариант работает, но медленно. Если требуется быстрое наполнение — единственная разумная платная альтернатива SerpAPI (~$75 разово за 10 000 запросов).

## Что нужно подготовить перед стартом

**Данные:**

- Список позиций с артикулами производителя (Manufacturer Part Number). Важно: артикулы дистрибьютора (Mouser Part Number, Digi-Key Part Number) отличаются от производительских — поиск нужно вести именно по MPN.
- Название компонента — нужно как резервный поисковый запрос при отсутствии результата по артикулу.

**Доступы — зарегистрировать заранее:**

1. developer.digikey.com — создать приложение, получить ClientId + ClientSecret (1 день)
2. mouser.com/api-hub → Sign Up → подать заявку на Search API (1–2 дня на одобрение)

**Хранение результатов:**

- Таблица или база данных с полями: артикул, URL изображения, источник, статус (approved / not_found), дата получения.
- Отдельная очередь позиций со статусом not_found для ручной обработки.

## Риски и как их снизить

**Фото технически получено, но не соответствует компоненту**  
Актуально для Mouser при запросе по keyword вместо точного MPN. Решение: всегда искать именно по Manufacturer Part Number, не по ключевому слову.

**Digi-Key или Mouser не знают артикул**  
Нормально для снятых с производства чипов и серого рынка. Для таких позиций — ручной поиск или добор через SerpAPI.

**Лимит исчерпан раньше времени**  
Расставить приоритеты: сначала позиции с высоким оборотом. Использовать оба дистрибьютора параллельно, чтобы распределить нагрузку.

**Регистрация Mouser затягивается**  
Подать заявку в первый день. Пока идёт одобрение — запустить наполнение только через Digi-Key.

## Итоговая рекомендация

По состоянию на 26.05.2026 рабочий бесплатный пайплайн состоит из двух источников: **Digi-Key API + Mouser API**. Google CSE закрыт для новых пользователей и уходит с рынка в начале 2027 года. Nexar — только для тестирования.

Комбинация Digi-Key + Mouser покрывает 80–90% стандартной номенклатуры запчастей ноутбуков. Оставшиеся позиции (редкие BGA-чипы, снятые с производства серии) требуют ручной обработки или разовых платных запросов.
