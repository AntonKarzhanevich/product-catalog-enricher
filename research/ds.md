# Исследование бесплатных API для получения изображений электронных компонентов
**Дата актуализации: 26 мая 2026 года**

## 1. Резюме

По состоянию на **26 мая 2026 года** все ключевые поставщики электронных компонентов (Mouser, DigiKey) продолжают предоставлять **бесплатные API** для доступа к своим каталогам. Это означает, что вы можете автоматически получать изображения для вашего каталога из 1000+ чипов **без прямых финансовых затрат**.

В ходе исследования также выяснились важные нюансы:
- **Mouser** — наиболее прозрачный вариант с чёткими лимитами (1000 вызовов/день).
- **DigiKey** — заявляет о бесплатности API, но для коммерческих нагрузок может потребоваться согласование с менеджером или переход на платный тариф.
- **Octopart** — переведён на платформу Nexar, где есть бесплатный ознакомительный доступ, но полноценное коммерческое использование уже платное.

---

## 2. Актуальные бесплатные API на 26 мая 2026 года

### 2.1. Mouser Search API (Рекомендуемый)

| Параметр | Значение |
|----------|---------|
| **Стоимость** | Бесплатно  |
| **Лимиты** | До 30 вызовов/минуту, до 1000 вызовов/день  |
| **Результатов на вызов** | До 50  |
| **Изображения** | ✅ Прямое поле `ImageURL` в ответе  |
| **Регистрация** | Через учётную запись Mouser  |

**Почему это лучший бесплатный вариант на сегодня:**
- Прозрачные лимиты, которые легко контролировать.
- `ImageURL` возвращается сразу в ответе.
- 1000 запросов/день теоретически позволяют обработать ваш каталог из 1000 чипов **за 1 день**.

**Ограничения**, о которых важно знать:
- Если в ответе на запрос приходит более 50 результатов, нужно реализовать пагинацию (постраничный перебор), так как за раз API отдаёт только первые 50 позиций .
- Для увеличения лимитов потребуется обращаться в службу поддержки Mouser — но для 1000 запросов/день это не требуется.

---

### 2.2. DigiKey API

| Параметр | Значение |
|----------|---------|
| **Стоимость** | Базовая версия — бесплатно  |
| **Лимиты (стандартные)** | ~1000 поисков в день по неофициальным данным  |
| **Лимиты (production)** | ~240 запросов/минуту после согласования  |
| **Изображения** | ✅ Через метод `get_product_media` |
| **Регистрация** | Через DigiKey API Solutions Portal |

**Важные обновления на 2026 год:**

По данным официального форума DigiKey (апрель 2026 года), существуют следующие нюансы :

1. **Стандартные лимиты ограничены** — по умолчанию система может обрабатывать около 500 артикулов.
2. **Для больших объёмов** (как в вашем случае — 1000+) **требуется согласование**. DigiKey официально заявляет: *"Для стандартных API клиент ограничен 1000 поисков в день. Большие объёмы доступны, но должны быть одобрены менеджером по продажам"* .
3. **Технические рекомендации от разработчиков DigiKey**: для массового поиска по артикулам используйте `product-details endpoints` с пагинацией (skip/take), а не поисковый метод .

**Вывод по DigiKey:** 
Бесплатный доступ — да, но для стабильной работы с 1000+ позиций потребуется коммуникация с DigiKey и, вероятно, переход на Marketplace/коммерческий тариф .

---

### 2.3. Octopart (Nexar) — Больше НЕ Бесплатный для Коммерции

**Важное изменение:** Octopart API переведён на платформу Nexar. Бесплатный доступ существует только для **ознакомительных и тестовых целей** .

- **Бесплатно:** Только evaluation (ознакомительный) доступ через портал Nexar .
- **Для коммерческого использования:** Требуется регистрация платного плана.
- **Для вашей задачи (коммерческий сайт):** Octopart/Nexar НЕ является бесплатным вариантом.

---

### 2.4. Сторонние API — DigiKey Scraper (НЕ бесплатный)

Сервисы вроде Bright Data или Omkar Cloud предлагают готовые API для сбора данных с DigiKey .

| Сервис | Бесплатно | Условия |
|--------|-----------|---------|
| **Bright Data** | ❌ | Есть бесплатный пробный период на 1000 запросов (1 неделя), далее от $1.50/1000 записей  |
| **Omkar Cloud** | ⚠️ Частично | 100 бесплатных запросов в месяц, далее от $16/мес  |

**Вывод:** Эти сервисы не являются полностью бесплатными для постоянного использования. Подходят только для тестирования или как резервный источник.

### Пошаговый план

**Шаг 1. Зарегистрируйтесь в Mouser API**
- Создайте учётную запись на Mouser.
- Заполните форму запроса Search API .
- Получите API-ключ по электронной почте.

**Шаг 2. Напишите скрипт для работы с Mouser API**
- Используйте метод поиска по номеру детали.
- Извлекайте поле `ImageURL`.
- Учитывайте лимит: 30 вызовов в минуту (делайте паузы между запросами).

**Шаг 3. Обработайте 1000+ артикулов**
- При 1000 запросах/день вы управитесь за 1-2 дня.
- Сохраняйте полученные URL изображений в базу данных.

**Шаг 4. Настройте резервный канал (DigiKey)**
- Если Mouser не находит изображение для какого-то чипа.
- Обратитесь в DigiKey для увеличения лимитов (если нужно).

## 5. Важные предупреждения на 2026 год

1. **Mouser — самый надёжный бесплатный вариант.** Его лимиты (1000/день) известны и стабильны. Никаких скрытых ограничений не обнаружено .

2. **DigiKey бесплатен только на бумаге.** По данным форума DigiKey (апрель 2026), стандартные лимиты занижены, и для 1000+ артикулов потребуется обращение к менеджеру .

3. **Octopart больше не бесплатен для коммерции.** Если вы найдёте старые гайды (2024 года и ранее), они будут неактуальны. Сейчас Octopart — это Nexar с платными тарифами .

4. **Сторонние скраперы не бесплатны.** Bright Data и Omkar Cloud предлагают лишь небольшие бесплатные пробные периоды .
